# AI Company — Optimization Roadmap

## Phase 0 — Critical correctness

- Implement typed assignment envelope and verdict taxonomy.
- Make DAG creation atomic and `run-ready` namespace-scoped.
- Enforce filesystem/control-plane isolation with pre/post mutation audit.
- Classify test-harness failures separately from product/company failures.

## Phase 1 — Core-loop reliability

- Add resumable workflow checkpoints, retry budgets and dead-letter handling.
- Run kill/restart/provider-timeout/orphan-worktree drills.
- Require every transition to persist input, output, owner, evidence and stop condition.

## Phase 2 — Decision intelligence

- Upgrade CEO Guild HOLD into a structured recovery mandate.
- Add adversarial proposal and high-evidence opportunity golden cases.
- Connect evidence → decision → prediction → outcome → learning.

## Phase 3 — Execution efficiency

- Build bounded context manifests and summarize only relevant evidence.
- Normalize provider telemetry and compare Codex/local/Antigravity on the same tasks.
- Replace deterministic LLM calls with validators/state machines where applicable.

## Phase 4 — Memory & learning

- Add provenance, ranking, contradiction and decay rules.
- Replay failed assumptions and verify future prioritization changes.
- Make verified improvement or valuable learning a hard cycle completion gate.

## Phase 5 — Founder leverage

- Automate normal rerun/recovery/escalation paths.
- Console/read model should show only decisions, failures, changed state, learning and Founder-required gates.

## Phase 6 — Controlled autonomy

- Prove A3 local execution, then a reversible staging slice.
- Keep production deployment, data deletion, migrations, rights and security changes human-gated.

## Phase 7 — Self-improvement

- Run five-cycle controlled evaluations and compare before/after outcomes.
- Permit architecture simplification/removal only when measured value improves.

Do not add more agents before Phase 0 and the product-impact trace are passing.
